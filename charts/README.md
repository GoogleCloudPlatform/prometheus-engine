# Helm Charts

> [!IMPORTANT]
> This directory contains internal Helm charts maintained solely for static manifest generation.
> They are not published as standalone Helm charts, are excluded from git release archives via `.gitattributes`, and should not be installed directly with `helm install`.

## Chart-to-Manifest Mapping

All charts share global image tags and defaults from [`values.global.yaml`](values.global.yaml) and are rendered into static manifests by [`./hack/presubmit.sh manifests`](../hack/presubmit.sh) (invoked via `make regen`):

| Source Directory / File                             | Generated Output Path                                                                             | Description                                                                                           |
|:----------------------------------------------------|:--------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------|
| `charts/operator/crds/`                             | [`manifests/setup.yaml`](../manifests/setup.yaml)                                                 | CRD YAMLs generated by `controller-gen` from `pkg/operator/apis/monitoring/v1` and combined via `yq`. |
| [`charts/operator/`](operator/)                     | [`manifests/operator.yaml`](../manifests/operator.yaml)                                           | Deployment manifest for `gmp-operator`, admission webhooks, and default `OperatorConfig`.             |
| [`charts/rule-evaluator/`](rule-evaluator/)         | [`manifests/rule-evaluator.yaml`](../manifests/rule-evaluator.yaml)                               | Standalone `rule-evaluator` Deployment and RBAC manifest.                                             |
| [`charts/datasource-syncer/`](datasource-syncer/)   | [`cmd/datasource-syncer/datasource-syncer.yaml`](../cmd/datasource-syncer/datasource-syncer.yaml) | Kubernetes `CronJob` manifest for syncing Grafana Prometheus data source OAuth2 tokens.               |
| [`charts/inject-gmp-sidecar/`](inject-gmp-sidecar/) | [`examples/inject-gmp-sidecar.sh`](../examples/inject-gmp-sidecar.sh)                             | Helper script rendered via a YAML wrapper and extracted with `yq`.                                    |

> [!NOTE]
> In `charts/*/_helpers.tpl`, rendering with the default Helm release name (`release-name`) intentionally omits Helm-specific management labels (`app.kubernetes.io/managed-by`, `helm.sh/chart`) so the generated files in `manifests/` remain clean static Kubernetes YAML manifests.

## Regenerating Manifests

To regenerate all static manifests and license headers from the repository root, run:

```bash
./hack/presubmit.sh manifests
# Or run full regeneration (CRDs, manifests, API docs, formatting):
make regen
```

To preview a single chart template manually from the repository root using the pinned `helm` binary from `tools/go.mod`:

```bash
go tool -modfile=tools/go.mod helm template ./charts/rule-evaluator \
  -f ./charts/values.global.yaml
```
